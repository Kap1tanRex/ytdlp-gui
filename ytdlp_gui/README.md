# yt-dlp GUI

Графический интерфейс для [yt-dlp](https://github.com/yt-dlp/yt-dlp) — скачивание видео и
аудио с YouTube (и других сайтов, поддерживаемых yt-dlp). Архитектура повторяет
соседний проект `ffmpeg_gui`: тонкий GUI на CustomTkinter, фасад `Application`,
шина событий, сервисы, очередь заданий с фоновыми потоками.

Оформление перенесено из «Стемницы» (`docs/design-system.md` того проекта):
шапка с логотипом, вкладками «Главная · Очередь · Настройки» и чипами
yt-dlp / FFmpeg / скорости; у каждой вкладки своя прокрутка и подвал;
уведомления — в левом нижнем углу. Палитра, шрифты и метрики заданы токенами
в `gui/theme.py` под теми же именами, что в документе (`BG`, `LINE2`,
`AMBER`…), компоненты — в `gui/widgets/design.py`.

## Возможности

- Скачивание **видео** с выбором качества/формата и контейнера (mp4/mkv/webm).
- Скачивание **только аудио** с извлечением в mp3/m4a/opus/flac/wav и выбором битрейта.
- Выбор **звуковой дорожки** (например, другого языка озвучки), если у видео их несколько.
- **Субтитры**: выбор языков, включая автоматически сгенерированные; можно
  скачать отдельным файлом (.srt), вшить в видео (требует FFmpeg) или и то, и другое.
- **Превью** видео: обложка, название, автор, длительность, дата, число просмотров,
  полный список доступных форматов (ID/разрешение/кодеки/размер).
- Очередь загрузок с прогрессом, скоростью, стадиями постобработки (слияние,
  встраивание субтитров/обложки), отменой и открытием папки результата.
- Плейлисты (по ссылке на плейлист, опционально).
- Настройки сети: прокси, ограничение скорости и **cookies** для приватных,
  возрастных и требующих входа видео — либо прямо **из браузера**
  (Chrome, Edge, Firefox, Brave, Chromium, Opera, Vivaldi, Whale; на macOS
  ещё Safari), либо файлом в формате Netscape. Выбранный браузер отменяет
  файл, чтобы источник cookies всегда был ровно один.
- **Обновления yt-dlp**: проверка релизов на GitHub, окно со списком изменений
  (что добавили и починили в каждой версии) и установка в один клик — с
  проверкой SHA-256 из файла контрольных сумм релиза. Проверка при запуске
  выключена по умолчанию: без вашего разрешения приложение в сеть не ходит.
- Оформление: тёплая тёмная тема «Стемницы» (светлой нет — контраст цветов
  рассчитан под тёмный фон; настройка `theme` в `config.json` больше не
  используется) и **масштаб интерфейса** 80–160 % — ползунок с шагом 5 % и
  горячие клавиши Ctrl+= / Ctrl+− / Ctrl+0. Масштаб применяется сразу и
  сохраняется в `config.json` (`ui_scale`).

## Запуск

```bash
cd yt-dlp
pip install -r ytdlp_gui/requirements.txt
python ytdlp_gui/main.py
```

Готовый `yt-dlp.exe` уже лежит в этой папке — GUI найдёт его автоматически.
Для слияния отдельных потоков видео/аудио, извлечения аудио и встраивания
субтитров/обложек дополнительно нужен **FFmpeg** — укажите путь в разделе
«Настройки», если он не будет найден автоматически.

## Сборка в один файл

```bash
pip install pyinstaller
pyinstaller ytdlp-gui.spec --noconfirm
```

Результат — `dist/ytdlp-gui.exe`: один самодостаточный файл, который можно
перенести куда угодно и запустить из любого каталога. Внутрь вшиты переводы
интерфейса и сам `yt-dlp.exe` вместе с каталогом `_internal` (лежащий в
проекте yt-dlp собран в режиме onedir — без `_internal` он падает с
«Failed to load Python DLL» и молча ничего не выводит).

Порядок поиска бинарников: путь из настроек → каталог рядом с `.exe` и его
подкаталог `bin` → вшитая копия → `PATH` → стандартные каталоги системы.
То есть свежий `yt-dlp.exe`, положенный рядом с приложением (или в `bin`),
имеет приоритет над встроенным — обновлять можно без пересборки.

**FFmpeg не вшивается**: он нужен не всегда (только для слияния потоков,
извлечения аудио и встраивания субтитров/обложек), весит больше самого
приложения и обычно уже установлен. Приложение найдёт его в `PATH` или по
пути из настроек.

## Обновление yt-dlp

YouTube меняется часто, и устаревший `yt-dlp` перестаёт скачивать видео —
поэтому обновление встроено в интерфейс (вкладка «Настройки» → «Обновления
yt-dlp», либо `Ctrl+U`; когда обновление найдено, чип yt-dlp в шапке
становится жёлтым и открывает окно по щелчку):

1. **Проверить обновления** — запрос к GitHub Releases репозитория
   [yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp). Если есть версия новее
   установленной, открывается окно «Доступно обновление» с разобранным
   описанием релиза: разделы (Core changes, Extractor changes, …) и списки
   изменений вместо сырого Markdown.
2. **Что нового** — то же окно, но с историей последних релизов, независимо
   от того, установлено ли обновление.
3. **Скачать** — загрузка и установка идут прямо в окне, с прогрессом.

Что делается для безопасности: только `https` и только домены GitHub,
ограничение на размер ответа и файла, обязательная сверка SHA-256 с
опубликованным в релизе `SHA2-256SUMS` (не совпало — файл не
устанавливается), запись через временный файл рядом с целью и атомарная
замена. Ничего не устанавливается само.

Куда попадает новый `yt-dlp`: если текущий бинарник лежит в обычном
каталоге — он заменяется на месте; если используется копия, вшитая в
onefile-сборку (её каталог временный), файл кладётся в `bin` рядом с
`.exe` — этот каталог приложение просматривает раньше вшитой копии.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Enter` | добавить ссылку из поля ввода |
| `Ctrl+V` | вставить ссылку из буфера и добавить (когда фокус не в поле ввода) |
| `Delete` | убрать выбранное видео из списка (не в поле ввода) |
| `Ctrl+Enter` | скачать выбранное видео |
| `Esc` | остановить текущую загрузку |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | вкладки «Главная», «Очередь», «Настройки» |
| `Ctrl+L` | журнал yt-dlp |
| `Ctrl+U` | проверить обновления yt-dlp |
| `Ctrl+=` / `Ctrl+−` | масштаб интерфейса ±10 % |
| `Ctrl+0` | масштаб 100 % |
| `F1` | справка |

Сочетания с Ctrl работают и при русской раскладке: на Windows они
распознаются по коду клавиши, а не по символу.

## Хранение настроек

| ОС | Каталог |
|---|---|
| Windows | `%APPDATA%\YtDlpGUI` |
| Linux | `~/.config/YtDlpGUI` |
| macOS | `~/Library/Application Support/YtDlpGUI` |

## Структура проекта

```
ytdlp_gui/
  app/          настройки, состояние сессии, шина событий, фасад Application
  core/         доменные модели, сборка команды yt-dlp, валидация, анализ ошибок
    updates.py  версии, сведения о релизе, разбор описания релиза
  services/     поиск бинарников, получение сведений о видео, превью,
                запуск процессов, очередь загрузок,
                update_service.py — GitHub Releases и установка обновлений
  gui/          главное окно и вкладки (главная / очередь / настройки)
    theme.py    токены цвета, шрифты, тема CustomTkinter, масштаб, заголовок окна
    fmt.py      числа, размеры и время в «голосе интерфейса»
    widgets/    компоненты (кнопки, сегменты, чипы, разделы, прогресс),
                шапка, страница с подвалом, строки списков, миниатюры,
                уведомления, диалоги
  resources/    переводы, шрифты IBM Plex и Unbounded (OFL), значок app.ico
```
